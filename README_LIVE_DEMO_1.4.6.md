# BusVision 辨識器 1.4.6 Live Demo UI + 誤報修正版

## 改動
- OCR 結果採用更保守路線號碼規則，未達門檻不報讀、不寫入紀錄。
- 自動辨識需要同一路線連續確認 2 次才報讀，降低沒看到數字卻一直說有數字的問題。
- 移除大面積中央結果卡，改成辨識成功才出現小型浮動視窗。
- 下方主操作改成 4 顆較漂亮的玻璃風格按鈕：啟用相機、立即辨識、拍照辨識、自動辨識。
- 鏡像與靜音移到右上角，避免佔用底部主要操作區。

## 建議 demo 流程
1. 啟用相機。
2. 對準公車車頭或照片。
3. 先按「立即辨識」。
4. 確定畫面穩定後再用「自動辨識」。
5. 若 OCR 現場不穩，可使用 Demo 932/939/916 展示 UI、TTS、紀錄流程。
