# BusVision Recognizer 1.4.13 - Text Block First

本版針對 932 公車照片辨識錯誤做調整：

- 即時辨識與拍照辨識都先尋找車頭內的文字方塊候選區。
- 加入類似車牌定位的影像處理流程：邊緣密度、明暗混合、水平長寬比與候選框 NMS。
- OCR 改成數字優先，保留 Q/O/I/Z/S/B/G 等常見誤判字元並在後處理時轉成數字。
- 修正 Q32 類型可回推為 932 的問題。
- 紀錄中保留最多 8 個候選框，方便查看到底有沒有框到正確文字區塊。
- 不再只靠固定 ROI，例如上方 LED、擋風玻璃、中央號碼牌；固定 ROI 只當備援。

測試重點：
1. 啟用相機。
2. 對準 932 公車照片。
3. 按立即辨識。
4. 到紀錄查看候選框與 crop 是否有框到真正的 932。
