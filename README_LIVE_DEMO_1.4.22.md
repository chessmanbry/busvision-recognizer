# BusVision 辨識器 1.4.22 stable compact UI

本版回到 1.4.20 的穩定四功能介面，不採用 1.4.21 的全畫面進度浮層，避免看起來卡死或阻擋操作。

## 修改重點
- 保留四個核心功能：立即辨識、拍照辨識、匯入圖片、自動辨識。
- 刪除 Demo 932 / Demo 939 / Demo 916 與手動輸入記錄區塊。
- 刪除採集資料分頁，只保留首頁、辨識、辨識紀錄。
- 限制直向使用。
- 立即辨識會自行準備相機，不再放「啟用相機」黃色按鈕。
- 保留 1.4.20 已能辨識 932 的紅色 LED / YOLO / OCR 流程，不套用 1.4.21 的阻塞式浮層。
